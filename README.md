# OBS 자동 크로마키

제작자 **SunjooAn** · 버전 **1.3** · Windows x64 · OBS 32/33 대상

고정 카메라와 크로마 배경지를 사용하는 방송을 위한 OBS 네이티브 GPU 필터와 도킹 패널입니다. v0.3에서 가져온 GPU 셰이더와 Lua 계산 모듈을 사용하며, 스트로크 기반 다중 색상 정밀 모드를 제공합니다.

배포 파일은 `dist/OBS-auto-chroma-v1.3-obs32-win64.zip`과 `dist/OBS-auto-chroma-v1.3-obs33-win64.zip`입니다. 각 ZIP에는 재빌드할 수 있는 `source/`와 SHA-256 목록이 포함됩니다. 도크·창·필터 목록의 이름은 **자동 크로마키**, 내부 메뉴의 제작자·버전 표시는 **SunjooAn · v1.3**입니다.

## 사용 순서

1. OBS 버전과 일치하는 패키지를 사용합니다. OBS 32용 DLL과 OBS 33용 DLL을 혼용하지 않습니다.
2. `독` 메뉴의 `자동 크로마키`를 엽니다.
3. 카메라 소스를 선택합니다. 새 필터는 처음에 원본을 통과시킵니다.
4. 필요하면 미리보기에서 분석·보호·지움 영역을 그립니다. 보호 영역이 지움 영역보다 우선합니다.
5. **자동 맞춤** → 원본/결과/알파 비교 → **결과 적용**을 누릅니다. 미리보기만 바뀐 후보는 적용 전까지 송출에 반영되지 않습니다.
6. 결과가 마음에 들지 않으면 **되돌리기**로 적용 전 설정과 기존 크로마키의 켜짐 상태를 복원합니다.

빈 배경 학습은 사람·손·그림자·보여 줄 물건을 치운 상태에서 사용합니다. 학습 당시 화면에 있던 진열대·소품도 배경으로 저장되어 지워집니다. 인물 인식 AI 기능이 아닙니다.

도크의 사진 합성은 미리보기용입니다. 실제 배경 영상·사진은 OBS의 미디어/이미지 소스를 카메라 아래에 배치합니다. 방송·녹화 중에는 보정·학습·적용·초기화를 차단합니다. 되돌리기는 복구 목적으로 허용합니다.

## 스트로크 정밀 모드

도크는 **왼쪽 큰 미리보기 / 오른쪽 조정 메뉴**로 구성됩니다. 가운데 구분선으로 너비를 조절합니다. **마우스 휠로 확대/축소**, **휠 버튼을 누른 채 드래그하여 이동**하며 `−`/`+` 버튼과 화면 맞춤도 제공합니다. 확대는 5–800%, 휠 확대는 커서 위치가 기준입니다. 상태 안내와 제작자·버전은 하단에 항상 표시됩니다.

미리보기는 **OBS에서 편집 중인 장면의 카메라 회전, 자르기, 크기 조절**을 반영합니다. **스튜디오 모드에서는 왼쪽 미리보기 장면을 우선**하고, 해당 소스가 없으면 프로그램 장면을 찾습니다. 일반 모드에서는 현재 장면을 사용합니다. 같은 소스가 여러 번 배치되면 선택 항목이 우선입니다. 독은 선택한 소스를 가운데에 표시하고, 화면 맞춤에서는 장면 캔버스와 소스 크기를 함께 고려합니다. 100%는 OBS에서 조정된 소스의 픽셀 크기를 사용합니다. 영역과 스트로크는 원본 카메라 좌표로 저장합니다.

보호 영역, 지움 영역, 국소 범위를 고른 뒤 **그리기 도구**에서 사각형·원·타원·펜을 선택합니다. 영상 주변 여백에서 시작해도 보이는 영상 안쪽만 선택됩니다. 펜은 클릭으로 직선 점을 만들고, 누른 채 끌면 양쪽이 연결된 곡선 핸들이 생깁니다. 노란 시작점 가까이를 클릭하거나 Enter를 눌러 닫습니다. 가운데 분할선을 끌면 두 패널의 너비가 바뀝니다.

마스크 유형을 고르고 **기존 영역 편집**을 누르면 점·핸들 또는 도형의 모서리가 나타납니다. 안쪽을 끌면 위치를 옮기고, 모서리를 끌면 크기를 조절합니다. **Alt를 누른 채 핸들을 끌면 잡은 쪽만 움직입니다.** 직선 점도 Alt를 누른 채 끌어 곡선으로 바꿀 수 있습니다. 윤곽선을 클릭하면 점을 추가하고, 점을 클릭한 뒤 **Delete**를 누르면 삭제합니다. 닫힌 마스크에는 최소 세 점을 남깁니다. 사각형·원·타원에 점을 추가하면 펜 경로로 전환합니다.

이미 적용한 국소 스트로크는 목록에서 선택하고 **선택한 국소 스트로크 범위 수정**을 누릅니다. 1.1에서 저장한 잘린 원·타원은 편집 가능한 윤곽점으로 열립니다. 1.2에서 저장한 핸들은 처음 열 때 대칭을 유지합니다. 편집을 마치면 **결과 적용**을 누릅니다.

**분리 창**을 누르고 창 테두리를 끌면 전체 창 크기를 바꿀 수 있습니다. **최대화**는 화면에 크게 맞추며 다시 누르면 복원합니다. **전체화면**은 창을 분리해 표시하고 **Esc** 또는 **전체화면 종료**로 이전 도킹/분리 상태와 창 크기로 돌아갑니다.

사용 순서: **카메라 선택 → 자동 맞춤 → 결과 확인 → 상단 알파 → 배경색 추가 스트로크 → Despill 조절 → 결과 적용**. 상단 **원본·결과·알파** 버튼은 항상 표시합니다. 알파 상태에서 그리면 그리는 동안과 끝난 뒤에도 알파를 유지하고, 결과 상태에서는 컬러 결과를 유지합니다. 색 추출은 어느 보기에서도 고정된 원본 프레임을 사용합니다.

정밀 모드를 선택하고 부족한 배경에 **배경색 추가** 스트로크를 그립니다. 진한 배경과 밝은 하단처럼 다른 색을 별도로 선택할 수 있습니다. **선택색 제외**는 배경으로 선택하지 않을 색을 지정합니다. 같은 색의 배경에도 영향을 주므로 위치 기반 보호 마스크와 구분하세요. 스트로크는 최대 16개, 한 획의 색 샘플은 최대 64개이며 목록에서 켜기/끄기·삭제·실행 취소할 수 있습니다.

**국소 보정**은 지정한 도형 안에 추가한 색 보정을 적용합니다. 강제 지움은 영역 안의 인물까지 투명하게 만들 수 있으므로 배경색 보정과 구분해 사용하세요. 머리카락은 확대 화면과 검정·흰색·체커·알파 미리보기에서 확인하고 **경계 보정**, **부드러움**, **Despill**을 따로 조절합니다. 각 슬라이더는 숫자 입력과 연결되어 있으며 옆의 **순환 화살표 아이콘**을 누르면 기본값으로 복원합니다. Despill은 배경색 번짐을 줄이는 색 조정이며 투명도를 바꾸지 않습니다.

스트로크는 그리기 시작한 원본 프레임에서 색을 읽습니다. 화면의 같은 위치를 영구적으로 지우는 페인트 기능이나 사람을 추적하는 AI가 아닙니다. 기존 기본 색 키와 배경판 모드로 전환할 수 있습니다. Blackmagic Design의 코드나 3D Keyer 엔진을 포함하지 않습니다.

## 설치

OBS를 종료하고 패키지를 **사용할 OBS 설치 폴더**에 풉니다. 기존 전역 설치를 자동 변경하지 않습니다. 포터블 OBS로 먼저 확인하는 것이 좋습니다.

- OBS 32: `obs-plugins/64bit/sunjoo-auto-chroma.dll`와 `data/obs-plugins/sunjoo-auto-chroma/`
- OBS 33: `plugins/sunjoo-auto-chroma/sunjoo-auto-chroma.dll`와 같은 폴더의 `data/`
- OBS 33의 일반 설치는 `C:/ProgramData/obs-studio/plugins/sunjoo-auto-chroma/`에도 설치할 수 있습니다. 포터블 모드에서는 해당 OBS 폴더 내부 `plugins/`를 사용합니다.

기존 Lua 필터와 함께 설치되어 있어도 이름이 다른 필터로 등록됩니다. 적용 시 같은 소스의 기존 크로마키만 꺼 두고 상태를 백업합니다. 원래 Lua 파일은 삭제하지 않습니다.

## 빌드

Visual Studio C++ Build Tools, CMake와 버전별 OBS/Qt SDK가 필요합니다. ZIP에서는 먼저 `source/` 폴더로 이동합니다. 준비 스크립트의 다운로드 위치와 실제 사용 버전은 `docs/build-environment.md`를 참고하세요(ZIP: `source/docs/build-environment.md`).

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1 -ObsMajor 32
powershell -ExecutionPolicy Bypass -File scripts/build.ps1 -ObsMajor 33
```

소스 라이선스는 `LICENSE`에 있습니다. 출처 고지는 `native/THIRD-PARTY.md`와 `native/vendor/auto-chroma-v0.3/license.md`에서 확인할 수 있습니다.

ZIP 재생성은 `powershell -ExecutionPolicy Bypass -File scripts/package.ps1`로 실행합니다.

## 검증 상태

1.3은 **OBS 32.0.0/Qt 6.8.3, OBS 33.0.1/Qt 6.11.1**을 대상으로 빌드했습니다. 장면 변환, 미리보기 조작, 분석, 정밀 모델, GPU 필터 및 제공 샘플 회귀검사를 두 버전에서 수행했습니다. GPU 검사는 별도 테스트 프로그램에서 수행했으며 실제 OBS 창 검증은 생략했습니다. 재현 방법은 [빌드 및 검증 안내](docs/build-environment.md)에 있습니다.

제공된 `Woman presenting.mp4`의 정지 프레임으로 우측 하단 실제 알파와 인물 내부 보존을 검사하는 GPU 시험을 추가했습니다. 최신 검증 결과는 `docs/04-report/obs-auto-chroma-precision.report.md`를 참고하세요. 원본 Lua 대비 동급 이상 또는 Resolve와 동급 화질을 선언하지 않습니다. HDR은 지원하지 않습니다. 미리보기는 최대 4K 픽셀 수, 프레임 수집은 512MiB로 제한합니다. 4K의 30장 빈 배경 학습은 이 한도를 넘으므로 1080p를 사용하세요.

취소는 프레임별·계산 단계 사이에서 확인합니다. 긴 계산 한 단계가 끝날 때까지 ‘취소 처리 중’이 표시될 수 있습니다. 도크의 설정 변경 잠금은 OBS 필터 속성 창의 직접 수동 편집까지 잠그는 기능은 아닙니다. 초기 버전에는 전용 단축키 등록을 포함하지 않았습니다.
